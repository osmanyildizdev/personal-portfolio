# Personal Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Overview

This project is designed to present my frontend development skills, academic background, and selected projects in a clean and professional way. It focuses on responsive layout, clear visual hierarchy, and user-friendly navigation.

## Features

- Responsive design for desktop and mobile devices
- Clean and modern user interface
- Project showcase section
- About and contact sections
- Built with semantic HTML, CSS, and JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- Git & GitHub

## Project Goals

- Build a professional portfolio for internship and job applications
- Practice frontend development fundamentals
- Improve responsive design skills
- Create a strong foundation for future React-based portfolio improvements
